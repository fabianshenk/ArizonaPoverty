The development project I created and presented, demonstrated and analyzed youth poverty issues within Arizona State based on demographic data via ACS and Census websites. This involved utilizing demographic data within the boundaries of Arizona. Within this demographic boundary, I enriched census tract data with demographic data and by use of spatial analysis and hot spot analysis finding areas where youth are prone to poverty to help visualize the necessity for local communities to focus resources to help. The best location to acquire such data is through American Community Survey, The United States Census Bureau and Living Atlas Layers available online through ArcGIS community. I completed an analysis and provided visual references with a few days and to produce a double-spaced 8 page report, jupyter notebook with the python code, and with visual references by December 4, 2019.
